# Computational Finance

<p class="ex-meta">Roma Tre University · MSc Finance & Technology · MATLAB</p>

Numerical methods for finance, implemented in MATLAB: from discounting cash flows and building
yield curves, to the statistics of returns and portfolio choice, to simulating prices and
pricing options.

Every exercise page follows the same structure: the **problem**, the **method** with its
formulas, the **code**, the **results** it produces, and the **takeaways**. The code is the
final version of my own solutions; comments are translated into English, and the results
and charts on each page come from running exactly that code.
